# 问数规范（配合 `wenshu_query` 工具）

本技能只讲**怎么问、怎么用结果**。取数动作由 `wenshu_query` 工具完成，本技能不可调用。

## 一、何时用

**用**：需要真实数值的经营/客户指标 —— 销售额、回款营收、利润、成本费用、预算与执行、
客户数量、商机、丢标明细、竞争对手配置、客户装置等。

**不用**：概念解释、闲聊、需要联网检索的信息、纯文档问答。

## 二、选哪个 scope

| 用户在问 | scope |
|---|---|
| 收入 / 回款 / 利润 / 成本 / 费用 / 预算 / 经营分析 | `business_operations` |
| 客户 / 商机 / 丢标 / 竞争对手 / 客户装置 / 销售活动 | `customer` |

拿不准时：先按最贴近的域试一次；若结果为空，**换另一个域重试一次**，仍为空才回复"没有数据"。

## 三、问法要求

1. **把时间范围写死成绝对区间**。平台按月汇总，用 `YYYY-MM`。
   - "今年" → 先看当前日期，再写成 `2026-01 至 2026-09`
   - 不要用"最近""上个月""这几周"这类相对表述 —— 取数服务不理解相对时间
2. **写清统计对象**。未指定时默认主体是「中控技术」；用户点了部门/公司/客户名，就用原话里的名称。
3. **一次只问一件事**。要三个指标就发三次，不要在一句里塞多个统计。
4. **要分组就明说**（"按月""按部门""按客户""按产品"），否则只返回汇总值。

## 四、结果怎么用

- 金额单位是**元**。回答时换算成**亿元**并保留两位小数（`1347365731` → `13.47 亿`）。
- **必须把口径写出来**（cbb 返回里的"查询的指标 / 维度 / 筛选条件"），让用户能核对。
- `data` 为空 = 该口径下**没有命中数据**，**不等于 0**。可以换时间范围或去掉筛选再试，但不能编造。
- 结果里的 `error` 非空表示**取数失败**（常见于数据连接器鉴权/路径问题），
  **不要**把它当成"没有数据"。

## 五、输出规范

先说结论（数字 + 单位），再附**口径**；需要时补一句业务解读（季节性、峰值月、异常点）。
多行结果用 Markdown 表格。**不要输出原始 JSON**，也不要罗列取数过程中的中间产物
（子问题、metric_ql 等），除非用户明确要求核对。
